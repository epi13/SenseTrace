# Phase 0 protocol v1

`phase0-protocol-v1` is the first frozen statistical protocol for deciding whether
SenseTrace's complete synthetic analysis pipeline is compatible with its known
null. A change to any item below creates a new protocol version; old calibration
artifacts are not silently reinterpreted.

## Construction

- Labels are generated independently of traces and are exactly balanced globally.
- The validation variant `group_stratified_balance` additionally assigns an equal
  number of `0` and `1` labels within each four-observation synthetic location,
  then randomizes the order within each location.
- Each replicate gets independent `acquisition_seed`, `label_seed`,
  `trace_seed`, `split_seed`, `model_seed`, and `permutation_seed` references.
- Synthetic datasets materialize explicit dataset, session, block, and location
  identities. Cyclic metadata IDs are not treated as independent acquisitions.
- The shuffled control reuses the exact parent traces and permutes labels within
  `synthetic_location_id`, preserving the declared exchangeability structure.
- Features are generated by `sensetrace.datasets.build_feature_matrix`; identity
  and grouping metadata are excluded from model inputs.

## Statistic and decision

For each independent materialized replicate, every enabled baseline records
balanced accuracy and AUROC. The tested statistic is:

```text
T = max(score - 0.5)
```

over enabled model/metric summaries. The empirical distribution of `T` over the
calibration null ensemble supplies the critical value at `alpha = 0.05`.
The resulting maximum-statistic p-value is the family-wise adjusted p-value for
the tested model/metric family. Individual metric p-values remain visible as
raw empirical p-values; they do not open the gate on their own.

The gate uses a fresh, independently materialized validation ensemble:

- null: no corrected departure from the calibrated null;
- shuffled: no corrected departure from the calibrated null;
- injected: detection at the predeclared injection strength at the configured
  minimum detection rate;
- pipeline calibration: the fresh-null false-positive estimate is reported with
  a Wilson 95% interval and must remain within the configured tolerance of alpha.

The same frozen rule is used for all conditions. A point estimate above 0.5 is
not a failure by itself.

The configured false-positive tolerance is an observed rate no greater than
`alpha + max(0.05, alpha)` with a Wilson lower bound no greater than `alpha`.

## Randomization evidence

The calibration report also runs a Monte Carlo label-permutation test on a fixed
injected dataset. Labels are permuted within the declared synthetic-location
strata, then the model is retrained and evaluated on the unchanged materialized
split. The report records the permutation count, scheme, seed, observed statistic,
null distribution, and plus-one empirical p-value.

## Claim boundary

This protocol calibrates software behavior on synthetic data. It does not claim
that a commodity host measurement reaches DRAM, that virtual offsets identify
DRAM rows, or that any physical result has passed confirmation.
